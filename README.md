# Телеграм сервис backend

### Сервис для сбора сообщений из телеграм каналов по фильтрам с помощью ИИ, и создания ИИ ответов на сообщение и отправки сообщения в комментарии.

Перед началом нужно создать или получить .env файл. Есть файл .env.example, который можно использовать в качестве шаблона.
Так же в .env файле есть поле ENCRYPTION_KEY, которое нужно заполнить, оно нужно для шифрования данных. 
Для этого нужно создать и запустить виртуальное окружение и запустить скрипт в корне папки:
```bash
python generate_encryption_key.py
```

Для работы с сервисом необходимо поднять контейнеры с помощью команды
```commandline
make local
```

Далее нужно накатить миграции
```commandline
make migrate-local
```

После этого сервис будет доступен, он должен работать в связке с фронтом, но есть 
документация по API, которая доступна по адресу:
```
http://localhost:8000/docs
```

## Как работает
Для начало нужно создать пользователя, после нужно создать проект, и добавить интеграцию
через телеграмм mtproto, для этого нужно получить API_ID и API_HASH, которые можно получить на сайте
```
https://my.telegram.org/apps
```

Далее нужно добавить прослушиваемые каналы по названию канала @durov, есть возможность добавить фильтры. И celery будет запускать фоновые задачи,
которые будут собирать сообщения по фильтру или без него, сначала он берет 10 последних.
Дальше если у сообщения есть комментарии, то можно ИИ ответ на сообщение, по заранее созданному промпту и отправить его в комментарии.
